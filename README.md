## start here

**[claude-chief-of-staff](https://github.com/loganhc-09/claude-chief-of-staff)** — how I turned Claude Code into a persistent AI chief of staff. The full architecture, written up, plus a plugin you can install in one command:

```
/plugin marketplace add loganhc-09/claude-chief-of-staff
/plugin install chief-of-staff@chief-of-staff
```

Then run `/chief-of-staff:setup`. It interviews you and scaffolds your own memory and daily brief. No coding.
